# 叩叩，老师在吗？

手机优先的教师节互动祝福网页：加载 → 声音选择 → 敲门 → 三条开门路径 → 25 位同学一起登场 → 拆信封、视频弹出 → 视频收回、回到原场景 → 拆开红枣礼盒 → 红枣旋转与三段寓意 → 暖光转场、信纸展开。

## 本地运行

需要 Node.js 22.13 或更新版本。

```sh
npm install
npm run dev
```

打开终端输出的 Local 地址，通常为 http://localhost:3000/ 。同一局域网的手机预览可运行 `npm run dev -- --host 0.0.0.0`，然后访问电脑局域网 IP 对应端口。推送到 `main` 后会由 GitHub Actions 自动发布到 GitHub Pages。

```sh
npm test           # 剧情、语言、拆信阈值及音频控制测试
npm run typecheck  # TypeScript 检查
npm run build      # 生产构建
```

## 修改祝福

只需编辑根目录 `config.js`，开发预览会自动更新。

- `emojis`：同学 Emoji 数组。默认 25 个，可直接替换每位同学的表情。
- `locales.zh.teacher` / `locales.en.teacher`：老师称呼及门牌。
- `locales.zh.story` / `locales.en.story`：所有剧情提示与开门选项。
- `locales.zh.letter` / `locales.en.letter`：信件称呼、段落和署名。`paragraphs` 可添加任意数量的段落，`\n` 表示段内换行。正文按纯文本渲染，HTML 不会执行。
- `locales.zh.gift` / `locales.en.gift`：礼盒提示、按钮与三段红枣寓意。三段分别讲“早日学有所成”、记住老师的期许，以及希望老师早些休息、日子甜一点。可以改各段内容；增加段数时也需扩展 `lib/story.ts` 中对应场景。
- `locales.zh.ui` / `locales.en.ui`：加载、声音选择、播放器、错误提示等界面文字。

中英文是两套独立文案。修改最终祝福时请同步修改两套内容，不会调用在线翻译服务。系统首选语言以 `zh` 开头时默认简体中文，其他语言默认英文。右上角“中 / EN”可以随时切换，选择保存在浏览器本地；清除该站点本地存储即可恢复系统语言默认选择。

## 替换音乐与封面

音乐配置在 `config.music` 中：

```js
music: {
  src: '/audio/top-of-the-world.mp3',
  title: 'Top Of The World',
  artist: 'Carpenters',
  album: 'A Song for You',
  cover: '/images/a-song-for-you.jpg',
  loop: true,
  volume: 0.45,
  videoDuckVolume: 0.1
}
```

把新文件放入 `public/audio` 和 `public/images`，修改对应地址即可。音量范围是 0–1。用户原始 MP3 保留在项目根目录，网页使用 `public/audio` 中的副本。来源见 `ASSETS.md`。

开场的“开启声音”是网页声音入口，无需麦克风权限。音乐在门完全打开后淡入。点击唱片暂停或续播，开门前只改变待播放状态。播放祝福视频时，背景音乐在 0.35 秒内从 45% 降至 10%，继续播放；视频暂停、结束或失败后，在 0.7 秒内恢复。`videoDuckVolume` 可修改视频期间的背景音乐音量（不高于正常音量）。视频自身音量保持不变；手动关闭的音乐不会被强制恢复。浏览器阻止声音时会出现“点击播放”提示。

## 替换祝福视频

当前视频直接使用 `config.video.src` 中的网络地址 `https://ik.imagekit.io/1fwccoblm/Untitled.mp4`，项目不保存视频副本。替换时修改该地址即可；推荐使用 H.264 MP4，以获得更广的移动浏览器兼容性。

视频元素会提前显示在信封中，呈现第一帧；抽出到拆封阈值或点击拆封时，直接播放同一个视频元素，再伴随光晕、星光和彩带放大到观看界面。静音进入时视频默认静音，也可用原生播放器开启声音；`muted: true` 可强制默认静音。

视频播放结束后，卡片收拢淡出，回到带有同学和已拆信封的办公室场景，显示“另外，我们还准备了一盒红枣”。点击礼盒或按钮后，盒盖飞起、暖光和彩带出现，红枣浮起旋转，随后按点击依次呈现三段寓意。最后点击进入信件，信纸在暖光中展开并逐字打出原来的正文。视频暂停或缓冲不会自动跳转；失败或等待超过 8 秒时可重试，也可继续到礼盒，仍会完整经过寓意和信件。

## 红枣展示与内存

- `config.gift` 配置本地礼盒插画和用户提供的 GLB 红枣模型；素材记录见 `ASSETS.md`。模型自带果实、枣柄和顶点色，不依赖外部贴图。
- 拆盒时才动态加载 Three.js 和三维素材。模型会自动旋转，也支持拖动、左右方向键及暂停按钮；界面不显示额外操作提示。切换中英文不重建三维场景。模型失败时显示礼盒插画和重试按钮，仍可阅读寓意。
- 自动旋转限制为 30fps、像素比最高 1.5；窗口隐藏、画面滚出视口或启用减少动态效果时停止自动绘制。离开礼盒会取消请求和动画，释放网格、材质、模型内纹理及 WebGL 上下文。
- 视频只预取元数据和第一帧，离开视频场景后清空媒体源并释放缓冲。音频解码时移交压缩数据，不同时保留 MP3 副本；暂停时释放整首解码缓冲，续播从浏览器 HTTP 缓存重新取得音频并保留进度，若缓存已被清除则会重新请求。卸载页面会中止未完成的音频和图片请求。
- 打字字符按段缓存，避免每打一个字都重新拆分整封信。加载计时器、音频节点和短时粒子画布在结束时清理。

## 使用与维护

- 手指或鼠标按住信封向上拖动，达到 55% 自动拆开；未到阈值松手则回弹。也可点击信封下面的文字按钮。
- 所有主要操作支持键盘焦点，按钮可用 Enter 或空格触发。
- 长信件沿整页滚动，不限制段落数量。
- 系统启用“减少动态效果”时停用唱片旋转、持续浮动及彩带动画。
- 背景音乐、语言偏好和剧情分别管理，切换语言不会重置剧情或音乐进度。
- 页面为纯前端交互，不包含账户、后台或访客数据存储。
